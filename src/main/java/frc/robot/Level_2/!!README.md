# Level 2 - Complete Intake Sequence

Goal:

Create an intake that:

1. Extends using Position PID
2. Spins rollers using Velocity PID
3. Creates a full intake sequence
4. Logs when rollers reach speed

Concepts:

- Position PID
- Velocity PID
- Encoders
- Commands Library
- Command Chaining
- Logging

Final Challenge:

Create a command that:

1. Extends the intake
2. Waits until extension finishes
3. Spins rollers
4. Logs "READY FOR NOTE"
5. Ends correctly

Before moving on:

Explain to a senior member:

- Difference between Position PID and Velocity PID
- What kP does
- Why commands need ending conditions
